# Bright Coffee Shop Sales Analysis

Bright Coffee Shop aims to increase revenue and improve product performance but lacks clear visibility into its sales data. The business does not fully understand which products drive the most revenue, what times of day generate the highest sales, and which items underperform.
Without these insights, decision-making around pricing, inventory, and marketing strategies becomes inefficient. This project addresses these challenges by analyzing transactional data to uncover actionable insights that can support business growth.

## Aim of the Project
The aim of this project is to analyze Bright Coffee Shop’s sales data in order to identify key trends, product performance, and customer purchasing patterns. The goal is to transform raw data into meaningful insights that can assist the business in making data-driven decisions to improve overall performance.

1. **Project Planning & Design**

   * Designed a data flow and architecture using Miro
   * Created a Gantt chart using Canva to manage the project timeline

2. **Data Preparation & Processing**

   * Converted raw Excel data into a structured format
   * Uploaded and processed the dataset in Databricks
   * Cleaned the data and corrected inconsistencies (e.g., pricing formats)
   * Created calculated fields such as total revenue (unit price × quantity)
   * Grouped transactions into time intervals for trend analysis

3. **Data Analysis**

   * Queried and aggregated data using SQL in Databricks
   * Analyzed product performance, sales trends, and time-based patterns

4. **Data Visualization**

   * Built pivot tables and charts using Microsoft Excel
   * Designed a visual presentation using Canva

5. **Presentation & Reporting**

   * Compiled insights and findings into a structured presentation
   * Delivered recommendations based on data-driven insights

## Summary of Results

The analysis revealed several important insights:

* Certain products consistently generate the highest revenue
* Sales peak during specific times of the day
* Some products underperform and require strategic attention
* Customer purchasing behavior varies across time intervals

These findings provide a clear understanding of business performance and highlight opportunities for improvement.

##Tools Used

* **Miro** – Project planning and data architecture design
* **Canva** – Gantt chart creation and presentation design
* **Databricks** – Data processing, transformation, and SQL analysis
* **Microsoft Excel** – Pivot tables, charts, and data visualization

##  Conclusion
This project demonstrates how raw transactional data can be transformed into valuable business insights. By combining data processing, analysis, and visualization techniques, the project provides actionable recommendations to improve sales performance and support strategic decision-making.
