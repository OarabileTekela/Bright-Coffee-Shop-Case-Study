# Bright-Coffee-Shop-Case-Study
In this project, I analyzed coffee shop sales data to understand how the business is performing. The aim was to identify trends in revenue, customer behavior, and product performance. Using Miro Diagram to draw up my plan, Ghantt Chart to track my progress report and i also used SQL for data analysis. I was able to turn raw data into insights that can help improve decision-making and drive business growth. Lastly i used Canva to complete my work with a presentation as Junior Data Analyst for the CEO”
